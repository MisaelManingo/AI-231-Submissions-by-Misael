# Flappy Bird

A lightweight, self-contained Flappy Bird game built with HTML5 Canvas and vanilla JavaScript. Runs completely offline in any modern web browser like Chromium without external dependencies or build steps.

## Features
- **Controls**: Flap using `Spacebar`, `Up Arrow`, or left mouse click / touchscreen tap.
- **Physics & Gameplay**: Smooth gravity, jump physics, tilting rotation, and accurate rectangular pipe collision.
- **Audio**: Built-in sound effects using the Web Audio API (no external audio files required).
- **Score System**: Live score tracking with persistent high score saved in `localStorage`.
- **Game States**: Start screen, active play with moving ground & clouds, and game-over modal with a restart button.
